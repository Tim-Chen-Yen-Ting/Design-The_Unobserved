# 分鏡行文慣例

> 基準檔：`01_學院篇.md`。機械層由 `scripts/check-style.sh` 檢查（Write／Edit 分鏡檔時會自動跑）。
> 判斷層檢查不出來，靠寫的人自己——那一節在最後面。

分鏡是**分鏡**，不是小說。每一行是漫畫的一格，不是一段敘述。

## 行的結構：三個欄位

一行由三個欄位組成——**角色**（必填）、**（動作）**（選填）、**內容**（選填，且只有兩種型別：`（想法）` 或 `話語`）。

窮舉就是這六種，沒有第七種：

```
- - - 角色（動作）
- - - 角色（動作）：（想法）
- - - 角色（動作）：話語
- - - 角色：（想法）
- - - 角色：話語
- - - 旁白（整行沒有角色欄位）
```

- 第三欄存在時，冒號是必須的；只有動作欄時不加冒號（`- - - 燁（很有自覺的開始撿那些被電暈的魚）`）。
- `角色（動作）話語` ——**漏冒號，是錯的**。
- **話語不加引號**。引號只用在被引述的書面文字（公文、報表、簡訊、筆記）。
- 想法一律包在 `（）` 裡，這是它跟話語的唯一區別。
- **畫外音**：鏡頭裡看不到人、但麥克風收得到時，角色欄寫成 `X的聲音`（`弦的聲音：啊！！！！！！！！！！！`，`01:2835`）。這不是第七型，只是角色欄的寫法，後面照常接話語。**說話者對讀者仍是未知**時不要硬湊，改用旁白把聲音帶出來（`墓園深處傳來一個聲音：為什麼...為什麼所有人都要阻攔我`，`01:2340`）——旁白報「聽得到什麼」是合法的，報「那是誰」才不是。
- **無聲對話**（生物電、信號）在語法上還是第二型，不是新型別，但**語義上是對白而不是內心**。兩種寫法都在用：01 放話語欄（`霆（會心一笑的用生物電向皓羚說到）：會的，勞煩校長大人費心了`，`01:2038`）；02 的霆↔弦戰術交流慣用括號式，靠動作欄標管道（`弦（在霆的腦內回復）：（別問我...）`）。**用括號式時，一段交流的第一行必須在動作欄標出管道**（`用生物電傳話`／`在霆的腦內回復`／`生物電`），否則它跟內心話無法區分，視角檢查也會誤判成越界。
- 省略號一律 `...`（三個半角點），不用 `…`。
- 行尾的 `// ...` 是**作者註解**（梗的說明、設計備註），不屬於任何欄位，也不是正文。
- 巢狀層級用 `- `／`- - `／`- - - ` 前綴，**分鏡台詞層一律 `- - - `**。
- **縮排的歷史**：`01_學院篇` 早期用的是另一套——`-` 是篇、`- -` 是序／始／中／末／尾、`- - - ` 才是內容，於是「以旁白開場的場景」其內容還要再縮一層變四格。01 後半與 02 之後放棄這套，統一三層。舊段落不追改，但**新寫的一律三層**。
- **章節專屬變體**：棋局章用 `角色（棋子代號）（動作）：內容`（例 `弦（Bishop）（語氣嚴肅）：...`）。這是該局的需求，不是常駐型別——除非某一節真的需要為每個角色掛一個固定標籤，否則不要用。

## 動作括號 ＝ 一格畫面

**唯一的判準：只看括號，畫得出這一格嗎。**

括號裡要是**外表看得到、或從外表推得出來的一拍**——`（點頭）`、`（滿頭大汗）`、`（二話不說）`、`（突然意識到什麼）`、`（很有自覺的開始撿那些被電暈的魚）`。「很有自覺」畫得出來（看他撿魚的樣子就知道），「已經做了九年」畫不出來。

01 的動作括號**中位數 7 字、p90 22 字**。

以下四條是同一個判準的機械變體，checker 全部會抓：

1. **不用代名詞開頭**。角色欄已經指名了，括號裡不再寫「他／她」——`（點頭）`，不是`（他點頭）`。01 全篇 **0 / 1561**。
2. **不放先後詞**——`然後`、`接著`、`於是`、`之後`。一格畫不出先後；而且格與格的接續是結構性的，不用寫出來（漫畫不會在畫格上寫「然後」）。要兩個動作就寫兩行。01 的動作括號**以先後詞開頭 0 / 1561**，句中含 `，然後/，接著` 只有 **1.2%**。
3. **時間跨度與回顧不進括號**。`九年來`、`一直是`、`從來沒有`、`已經做了很久` 是敘述者的話，不是鏡頭。01 **1 / 1561（0.1%）**。（`第一次`／`第七次` 這種當下可辨的計數不在此列。）
4. **不放沒有畫面的內心**。括號是鏡頭，不是腦內。**如果括號寫的是一個心理動作（把 X 跟 Y 並排、意識到、算完、明白），那整個括號都不該存在**——把那一行寫成 `- - - 角色：（想法）`。

**允許的長括號只有一種**：括號本身就是那個角色的**感知或認知狀態**，而且是持續的一個狀態，不是一串事件——例如然感受到因果線回避他們的那一段、皓羚初登場那一格。這類在 01 佔約 3%，是人物定義用的，不是常態。

## 核心原則：敘述靠動作與想法帶出來，不靠敘述性的詞

上面所有規則的來源。要讓讀者知道的事，讓角色**做出來**或**想出來**——不要用敘述句去說。轉換手法就一招：**把敘述改成第一人稱的想法**，內容全部留著，鏡頭還原成一拍。

```
✗ 龍淵（開始做一件他已經做了九年的事...把那個人的臉調出來）
✗ 龍淵（九年來那張臉一直是空的。因為不知道要恨誰，所以只好在那個空的位置上放了一個輪廓）
✗ 龍淵（很清楚接下來那一句）：（...）

✓ 龍淵（閉上眼）
✓ 龍淵：（...又來了。這個動作我做了九年）
✓ 龍淵：（把那張臉調出來。而那張臉一直是空的——我不知道要恨誰）
✓ 龍淵：（所以我在那個空的位置上，自己放了一個輪廓）
```

```
✗ 龍淵（把那件事做完了，卻發現他預期會來的那個東西沒有來...沒有解脫，沒有滿足）
✗ 龍淵（伸手把報紙撿起來，很仔細地折好，放回那個人的膝蓋上）：......
✓ 龍淵（跪在紙板旁邊）：......
✓ 龍淵：（...沒有解脫。什麼都沒有）
✓ 龍淵（把報紙折好，放回那個人的膝蓋上）
```

同一條也管旁白：旁白不可以拿來補敘述。想寫「這是他九年來第一次」，那句話要嘛是某個角色的想法，要嘛不寫。

## 旁白 ＝ 沒有掛在單一角色身上的那一格

旁白的功能就是**當旁白**，主要兩種：

1. **場景／時間建立**——不屬於任何角色的 exposition。`一段時間後`、`回去之後`、`很快便天黑了`、`在糖葫蘆攤販前`、`於是他們便回到宿舍了`。短，一句，交代完就走。
2. **靜態寬鏡頭**——一整格的構圖（見下方範本）。

01 也用旁白寫**沒有單一主體的事件**，戰鬥居多——`噗一聲，火苗燃起`、`箱子像是被無形的長繩拉扯，劃破長空直接砸在眾人面前`、`一棵大樹應聲而斷，燁像搬牙籤一樣把木材整齊堆好`、`整片小溪都被漫天雷光覆蓋，包含燁`。

不論哪一種，**不變量是：鏡頭看得到**。旁白不進任何人的腦。

**要寬鏡頭、要構圖，寫在旁白，不要塞進動作括號。** 動作括號掛在一個角色的一拍上，所以短；旁白是整格畫面，所以可以長。01 的旁白**中位數 29 字、p90 61 字**，最長 142——而動作括號中位數只有 7。

構圖旁白的範本（`01_學院篇.md:2575`）：

```
- - - 連續的好幾個閃光燈一閃而過，從時間的長河中截下了一張張永恆的片段。在彩色的煙火光芒下，
      那上面有著一個身著深藍素色浴衣臉上混合著冷酷與困惑的高大身影，一個粉色燦笑的可愛少女開心
      的比著耶，一個身著天空藍、臉上帶著不解但還是淺淺微笑著的高挑淑女，和一個身紅如火一般的
      健壯身影誇張的揮舞著拳頭
```

它 150 字，但它是**一張照片**——快門就是畫框。成立的原因有三個，寫寬鏡頭時照這三條檢查：

1. **每個子句是同一格裡的不同區域**，不是不同時間。空間並列可以長，時間串接不行。判準：能不能在一張圖上指出每一個子句。
2. **角色用顏色與輪廓指認**，不用名字——深藍浴衣的高大身影、粉色燦笑的少女、天空藍的高挑淑女、身紅如火的健壯身影。那是讀一張照片的方式。
3. **只有外觀、姿勢、表情**。沒有一個字進到任何人的腦子裡。

**反向的飄移也要注意**：02 的旁白中位數只有 18 字（01 是 29），而且總數比更長的篇還少——動作括號寫太長的同時，旁白寫得太碎。該給寬鏡頭的地方就給一整格。

## 語域不是文法

01（學院篇）比 02（盤古篇）輕鬆得多——`。。。。`、`～`、夾雜英文、`//` 註解梗。**那是篇章語域，不要拿來拉平盤古篇。** 本檔規範的是動作格與行的文法，不是玩笑密度。

# 檢查不出來的那一半

`check-style.sh` 能證明每一行**合法**，不能證明這一節**寫對了**。被退過的稿子每一行都合規，問題在內容：內心獨白太白話像敘述、或者意義不明、讀者不知道那一格的畫面是什麼。

那一半的防線是流程，不是規則——見 `CLAUDE.md`「寫分鏡的流程」。以下是判斷層的常見病灶：

- **內心獨白變成解說**。`（第一層：論功行賞。第二層：通知。第三層：預告）`——那是作者在編號，不是人在想事情。同一件事應該由**不同的人在不同的時間**碰到，而視角人物**碰不到的那一層要留白**（例如他找不到形容那個東西的第三個字，直到別人替他說出來）。
- **把「你知道我知道」寫出來**。這種東西只能演——在對方讀你的那一秒插一句無關的話（`茶涼了？`），兩個人都不提。寫成文字就死了。
- **連續超過 6～8 行同一個人的內心**。那就是一段散文。中間要插可觀察的拍子（對方添了茶、窗外的風），或者根本該砍。
- **視角人物替別人做總結**。`（她其實是在逃避）` 這種要有**他讀得到的依據**（三天前的那件事、指節的顏色），而且結論要短。
- **把角色說不出口的東西寫成他說得出口的樣子**。說不出口就要用**失敗**演：起句斷掉、給兩個互相矛盾的答案、或者換一個答得出來的問題去問。

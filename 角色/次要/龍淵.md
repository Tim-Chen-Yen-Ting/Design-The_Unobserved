# 龍淵

> 派系與本源速查：[勢力/盤古.md](../../勢力/盤古.md)

**劇情功能**：蒼龍麾下策略型次要角色，自稱「蒼龍的左臂」，戲份已達次要角色量級（期末考核章龍淵篇獨立挑大樑，全程智鬥對線霆）。棋類美學，凡事精於算計，極少親自下場——傾向讓對局本身替他說話，而非炫耀武力。對霆抱持惺惺相惜的欣賞，行事帶有一種閒適的餘裕感（例如主動提前結束自己的對局、幫霆爭取额外三小時休息時間），但這份餘裕背後是精準的算計，不是單純的善意。對霆和然的關係心知肚明，選擇不點破、僅止於旁敲側擊的調侃。

**戰鬥定位**：全世界觀第一梯隊戰力，但強項不在輸出量級。真正的戰鬥手段是**純體術**（無花俏招式、近乎無敵的格鬥能力），Design本源不用於直接進攻，而是**賽前精算對手的招牌能力、現場手搓針對性反制道具**——例如面對霆的電磁系，手搓一個法拉利籠讓對方的電磁攻擊失效；面對弦的信號系，手搓絕對真空阻斷訊號傳遞；面對毒氣戰術，人手一瓶高壓氧反制；面對需要深海突襲的場合，人手一瓶氧氣筒解決環境限制。核心精神：**他的強，強在讓對手的王牌失效，而非自己祭出更大的王牌**——這與他「下棋」的人設完全一致：不是臨場發揮的創造力，而是早已算好每一種可能局面該準備什麼道具的未卜先知式針對性反制

**本源**：Design

**詮釋分支**：
- **Molecular Structure**——重新排列組合周遭或體內物質的分子結構，用於現場手搓上述反制道具。效果範圍受限於他「精確掌握」的分子結構種類：常見材料（金屬、氣體、基礎有機物）可隨手重組；複雜或罕見結構需要現場長時間「解析」，無法瞬間應用於未知物質
- **Organism Blueprint**——從元素層級構建具有自洽構造的生物。**明確的敘事限制**：效果受限於他實際「背誦記憶」下來的具體物種基因序列與構造。這代表：(1) 用於治療時，只需複製患者自身已有的健康細胞去填補患處，資源需求相對低；(2) 憑空創造全新物種、或重建他沒有背過的複雜生物構造，在敘事上應視為近乎不可能的量級——現實中連最簡單的原核生物基因體都是數百萬鹼基對，不能單靠「天賦異稟」跳過這個知識量門檻。此分支在戰鬥中極少使用，主要作為人設暗示（他的知識儲備廣度）
- **共同限制**：不論哪個分支，「精確操控」都需要前置時間讓他在腦中確認結構藍圖，無法瞬發；施法中可被打斷。因此他慣於**賽前佈局、戰前準備**，而非戰鬥中臨場創造——這也是為什麼他更像個帶著萬全準備進場的棋手，而非隨機應變的即興戰鬥者

**彩蛋**：學院篇期末章「龍淵局」（霆 vs 龍淵的西洋棋對局）1:1 映射真實棋局——Carlsen–Karjakin 2016 世界棋王賽 Game 10。懂棋的讀者看得出這是彩蛋；不懂棋的讀者會覺得這盤棋寫得異常真實專業（畢竟就是抄的）

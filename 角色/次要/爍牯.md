# 爍牯

> 派系與本源速查：[勢力/盤古.md](../../勢力/盤古.md)

**劇情功能**：盤古財政／經濟首長，珀彪派系幹將。黨爭章的正面對手（政策與輿論層），龍吟章弦的復仇對象（人口販賣資產管理的幕後責任歸於其名下）。十二生肖丑位，徽記為金色牛首。

**本源**：Value

**術式**：可量化任何概念——包含人力資本估值。**這是他人格的根**而非戰鬥手段：他在辯論台上說出「以平均報酬率計算，這個群體的社會消耗大於其產出」時，不是在修辭、也不是在辯解，他是在**讀自己本源給出的數值**。弦以 Signal 察覺到他全程都在施術，而那個術式沒有攻擊性——它在測量。這解釋了他為何從不動怒、從不閃避、也從不被說服：對他而言那些不是立場，是讀數。

**標籤**：死公雞、"what must be done has to be done"

**外觀道具**：細金屬框眼鏡，讀數字用的。辯論直播那天弦在鏡頭前見過，所以龍吟·尾裡那副帶血的眼鏡被放上桌時她兩秒就認出來——那是全篇唯一需要她辨識的遺物。

## 出身與清貧

西境旱村。十一歲以前每年春天走六公里擔水，一天四趟。十三歲那年村子因連續兩年無收成遷走，二百四十戶走剩一百零九戶。他一路考上來，是**盤古建國以來第一個不靠出身坐上財政首長的人**。

**他不貪，而這是最難處理的事實**。名下僅一間公寓、一台公務車——沒有不動產、沒有海外帳戶、沒有信託、沒有掛親戚名字的空殼。一個相信自己在蓋抽水站的人不需要貪。這使他無法被當成貪官清算，只能被當成**信念清算**。

## 有機器，沒有錢

十年任期內，行政調撥需要執行機構，於是長出一整串採購公司、運輸、倉儲、結算窗口——**名義上屬於財政部、實際上聽他一個人調度**。那些實體裡的人，位子是他給的，因為他的提拔標準是「能不能算」而不是「姓什麼」。

**核心結構（寫他的時候不要弄反）**：那串公司**登記在他自己名下、法律上是民營的**，不在財政部編制內。而他**一塊股利都沒有領過**，全部盈餘滾回去投進計畫。所以——

> **帳面上他值幾十億。生活上他值一間公寓。**

**為什麼要設在體制外**：部裡的公司要走採購法、要排預算年度、要接政治派任的人事。那種東西執行不了一個十二年的壓縮計畫。他要的是「我說動就動」，所以把工具設在體制外——**不是為了藏，是為了能用**。

**為什麼這仍然不是貪**：他從那台機器上沒有拿走一塊錢。股權對他是控制手段，不是財富。他住在那間公寓、開那台公務車、領薪級表上的數字。這一點是他整個人物的根：一個相信自己在蓋抽水站的人，不需要貪。

**但這是他唯一無法公開辯護的事**：一個財政首長私人持有全國行政調撥的整套執行機構——技術上合法，結構上無法解釋。而且它**從來沒有藏過**，一直在商業登記上公開。沒有人去調，因為那八項數字太漂亮了，沒有人想問漂亮的東西掛在誰名下。（弦的輿論戰也沒有先用這條——「首長持有物流公司股權」在證明危害之前只是報紙第十四版。危害成立之後，那些持股才回溯性地變得無法辯解。）

這條設定支撐四件事：
1. 珀彪命他「自己掏」賠償七十七家店（粗估三億）——那句話剛好落在**唯一一個他掏得出來的地方**。所以那道令不是罰款，是逼他親手把自己蓋了十年的機器一塊一塊賣掉，去賠四十一家豆腐店。他當場點頭，而且點得很快——快得不像在認錯，像在確認一筆帳
2. 賣完之後股權歸零、官職沒了、公務車繳回，只剩一間公寓 → 龍吟章**流落街頭**
3. 沈家買下那些股權，因此**真正繼承了他的經濟影響力**（股權＋合約＋通路＋關係）。而沈家接得動的唯一理由是上個月已挖走其體系內二成六的中階管理——「先買人、後買廠」，商戰第三招的收益延遲兌現，而全程沒有任何人違法
4. 淨結果：他沒有從那台機器上拿走過一塊錢，最後卻要用那台機器去付一筆算在他頭上的帳

## 政策與算式

- 珀彪給他的原始指令只有一句：**讓盤古的東西生產得出來**。沒有指標、沒有期限、沒有排除條件
- 他據此把目標函數設為「人均社會福利最大化」——與珀彪真正想要的「所有人都吃得上飯」在人口減少時方向相反。這是黨爭章「越權」指控的法理基礎
- **第一階段經濟改革**（啟動於五年前）：以四十年壓縮為十二年為目標，將全部可投產能灌入投資端。八項產出數字全部上揚（生鐵＋97%、鋼＋25%、煤＋94%、發電 2.5x、原油 2x、勞動力 2x、農機 39x、工業總產值＋118%），而實際購買力 −40%、日用品產量 −50%、牲畜總數 −40%、人口連續五年負成長四項從未進入報表——**因為那四欄從來不在他要交的表格裡**
- 他的推算：四十年路徑餓死一千一百萬，十二年路徑代價一百萬。龍淵驗算後承認量級正確、推導嚴謹；玄猿確認沒有任何一個切面能把飢餓歸零。**他的算式沒有被駁倒過**

## 關鍵行為特徵

- **語氣永遠是念表格的節奏**，無情緒起伏。唯一的破格是主動提起旱村那段——而那段話後來成為他最駭人的論據的前提（「二百四十戶走到一百零九戶，那一百三十一戶不是因為有人記住他們的名字才活下來的。是因為後來有人蓋了抽水站」）
- **從不失言**。黨爭章的敗因不是他說錯話，而是他在全國面前**誠實地做了自己**——而全國發現這個自己是什麼樣子。散場時他認為自己贏了道理
- **服從但不認錯**。被珀彪押到紀念碑前磕頭，動作標準得像在執行程序，起身後說「我服從您的指示。您有權決定優先順序，這一點我從來沒有異議...但我還是認為我的算式是對的」
- **對主角團全程使用正式敬稱**（顧卿／林卿／沈卿／周卿），包括被拔職之後。那是人格，不是客套
- 他被拔掉了，但**沒有被說服**——那套算式還在，等下一個願意聽的人
